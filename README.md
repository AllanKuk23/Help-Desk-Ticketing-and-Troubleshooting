# Help Desk Ticketing & Troubleshooting

## Project Overview

This project focuses on hands-on IT troubleshooting and help desk ticket management using SysDesks and ServiceNow.

SysDesks provides simulated technical support scenarios, while ServiceNow is used alongside each troubleshooting scenario to practice creating, managing, documenting, and resolving help desk tickets.

## Tools & Technologies

- **SysDesks** — Simulated IT troubleshooting
- **ServiceNow** — ITSM / Incident Management
- **Windows 11** — System and network diagnostics
- **Command Prompt / PowerShell** — Troubleshooting commands when applicable

## Workflow

1. Review the reported issue in SysDesks.
2. Create a matching incident or request in ServiceNow.
3. Troubleshoot the issue and document findings.
4. Apply the fix and verify the resolution.
5. Complete the ServiceNow ticket and document the case.
